# BHraytracer

Schwarzschild ブラックホール周りの光の測地線を RK4 で積分する
CPU レイトレーサー。降着円盤との衝突で色を付ける簡易版。

## ビルドと実行

```
make        # BHraytracer.out をビルド
make run    # 1000x1000 の PPM (P3) を標準出力へ
```

## 検証テスト

```
make test
```

`tests/test_geodesic.cpp` で、積分器が解析的に知られた結果と
一致するかを確認する:

- 光の曲がり角 (弱場展開 δ = 4M/b + (15π/4)(M/b)² との比較)
- 影の大きさ (臨界インパクトパラメータ b = 3√3 M)
- フォトン球 (r = 3M) の円軌道の維持と保存量ドリフト
- 近接通過時のヌル条件と角運動量のドリフト

単位系はシュバルツシルト半径 rBH = 1 (M = 0.5)。

このテストは、相対論レンダラーを GPU (GLSL) へ移植する際の
回帰テストとしての利用を想定している。
